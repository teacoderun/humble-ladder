# humble-ladder

Observability · Go · Vue

学习用的示例项目

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/humble-ladder.git
cd humble-ladder
go build ./...
```
